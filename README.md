## 🎯 这是什么？

**FormSight** 是一款面向数字画师、设计学习者以及美术从业者的**视觉直觉专项训练器**。

FPS 玩家会用 Aim Lab 练习微操定位与肌肉记忆，而画师在作画时，同样高度依赖大脑底层的**眼力与观察直觉**：
- *为什么起形总是不准？比例抓不准、线条角度有偏差？*
- *离开取色器就不会抓色？在复杂光影环境里看不出色温与明暗的相对推移？*
- *画画容易陷入局部细节，看不出画面整体的动态势线和黑白结构？*

FormSight 把传统美术学院中抽象、难以量化的“观察感觉”，拆解成了 20+ 个极简、可量化、可自适应升级的**眼力小练习**。通过记录你每次作答的微小误差与反应速度，动态调整难度，帮你打破大脑的具象认知偏见，建立扎实的造型与色彩直觉。

## 🎮 我们能练什么？

系统采用模块化设计（扩展包架构），覆盖美术底层核心观察力：

### 1. 寻星与几何定位 (Star-Hopping)
> 摆脱尺子与网格辅助，强化眼手对点位空间关系、距离比例与心智旋转的直觉抓取。
- **单锚点 / 双锚点 / 旋转双锚点**：观察左侧基准点位置，在右侧离散点阵中凭直觉盲点定位。

### 2. 绝对色感 (Color Recognition)
> 科学戒掉取色器依赖，建立精准的色彩心智模型。
- **色相 (Hue)**：在 360° 色轮上精准辨识色相角度。
- **明度 (Value) 与 饱和度 (Sat)**：评估色彩的纯粹深浅与鲜艳度。
- **综合拾色 (Match)**：同时调节色相、饱和度与明度，全维度还原目标色彩。

### 3. 相对色感与环境光 (Relative Color)
> 抵抗环境视错觉，训练在复杂光影下捕捉色彩相对偏转与固有色推移的能力。
- **色彩矢量迁移**：根据 A➔B 的色彩变化规律，推导出 C➔D 的同向推移色。
- **明度与色相反差补偿**：在不同底色诱导下微调中心色，使两端在感知上完全一致。
- **环境穿透判别 (2AFC)**：看穿强对比背景造成的视觉假象，二选一快速找出客观物理明度更高的一侧。

### 4. 正负形观察 (Negative Space)
> 学会“画外部留白来精准反切主体”，是职业画师快速准确起形的核心技巧。
- **负形占比评估**：用滑块估计剪影外部留白占整幅画面的面积百分比。
- **负形面积快判 (2AFC)**：两选一快速比对不规则外形的留白大小。
- **负形边界反切定点**：通过负形空隙挤压的转折形态，在点阵中精准找回被截断的关键转折顶点。
- **负形轮廓记忆匹配**：瞬时记忆负形空隙特征并在候选中还原。

### 5. 角度感知 (Angle Perception)
> 剥离画面干扰，以极简线条强化对转折角度与平行线斜率的敏感度。
- **夹角大小估算**：滑块精准判定 0°~180° 射线夹角。
- **角度二分对比**：快速辨识两组不同旋转角度的夹角谁大谁小。
- **平行线基准辨识**：在随机干扰项中找出与基准线绝对平行的线段。

### 6. 透视空间感知 (Perspective)
> 锤炼空间立体感与比例直觉。
- **透视灭点汇聚感**：旋转线段使其与已有透视基准线精确交汇于同一超远灭点 (VP)。
- **比例与黄金分割盲切**：在线段上直接点击切出 1/2、1/3、1/4 或黄金分割位置。
- **空间比例迁移**：将水平参考线上的目标点比例准确投射到倾斜线段上。
- **断线完形连续性 (格式塔)**：辨识穿透遮挡物后保持真实贯穿的延伸线。
- **3D 结构空间翻转**：结合正交三视图标点，在 3D 透视立方体点阵中定位三维坐标。

### 7. 视知觉概括与细化 (Abstraction & Concretization)
> 训练“眯起眼睛看大关系”的艺术提炼力与自顶向下的还原力。
- **动态势线提取**：从离散粒子流中提取主导动态势线 (PCA 算法)。
- **折线低模大形**：过滤繁琐细节，抓取剪影底层最坚固的折线大框架。
- **黑白素描归组 (Notan)**：调节二值化阈值，压榨出黑白咬合最平衡的素描大关系。
- **主调色群提炼**：穿透多色马赛克杂色，找出代表画面全局基调的加权主色。

## ⚡ 核心功能特性

- **自适应难度引擎**：
  - 支持 **轮次评估模式**（每 10~20 题检验胜率决定晋级或降级）与 **阶梯挑战模式**。
  - 难度随你的水平动态调整，始终保持在具有挑战性但不会挫败的心流区间。
- **日常定制训练流 (Training Plan)**：
  - 自由编排多阶段训练计划（如：*15题色相 + 20题双锚点 + 20题折线大形*）。
  - 内置官方推荐流，支持一键切换、收藏、导入与导出 JSON。
- **弱点诊断与数据看板**：
  - **八向方位罗盘** 与 **12 色相环盲区**：直观展示你在哪些角度或色系上最容易产生偏差。
  - **空间偏置散点图**：分析手眼协调中是否存在系统性往左/右偏的倾向。
  - **训练打卡热力图**：完整记录你的生涯练习足迹与能力等级成长轨迹。
- **纯离线与极致响应**：
  - 基于 PWA + IndexedDB 本地数据库构建，无需登录、数据不出本地，无网环境下依然流畅训练。
  - 支持全键盘快捷操作（空格确认、1/2 键快速二选一、Esc 随时结算），沉浸无干扰。

## ⌨️ 常用快捷键

| 按键 | 功能说明 |
| :--- | :--- |
| `Space` (空格) | 提交滑块数值 / 选项提交 / 手动切下一题 |
| `1` / `2` | 2AFC 二选一快速选择左/右区域 |
| `1` ~ `4` | 快速选中第 1 ~ 4 个候选项 |
| `Esc` | 退出 |
| 任意键 / 点击 | 闲置休眠保护后一键恢复计时与训练 |

## 🛠️ 本地运行与开发

项目采用超轻量的前端技术栈，无需配置复杂后端：

```bash
# 1. 克隆代码仓库
git clone https://github.com/doucx/FormSight
cd FormSight

# 2. 安装依赖
npm install

# 3. 启动本地开发服务
npm run dev

# 4. 代码检查与测试
npm run check
npm run test

# 5. 构建生产产物
npm run build
```
