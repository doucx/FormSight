# 训练方法论：感知难度、阈值自适应与指标语义

> 状态：现行（对应 v0.6.x）
> 读者：产品评审、卡片算法作者、教学评审
> 关联：[`card-design-spec.md`](./card-design-spec.md)、[`architecture.md`](./architecture.md)

本文回答三个问题：**什么叫"练会了"、"难度"是什么量、界面上该显示什么。**

## 1. 能力的定义

> 能力 = 你能以约 **80% 正确率**稳定完成的参数集。

这是全项目的锚点。它把"画画凭感觉"翻译成一个可测量对象：不是"能不能做对"，而是"在多细的尺度上还能做对"。

推论：

- 难度必须连续可变，且能被独立标定（Level 1–35）。
- 一次作答的对错几乎没有信息量，**一个难度档位上的稳定表现**才有。
- 练习的目标不是刷高正确率，而是把 80% 的边界往外推。

## 2. 自适应算子

`src/core/engine/adaptiveEngine.ts`，`MAX_LEVEL = 35`。

### 2.1 阶梯模式（staircase，默认）

- 连续 **3 次**命中 → 升一级（默认 `step = 3`；`isFineGranularity` 时为 1）。
- 1 次未命中 → 清零连击，按阶梯规则下探。
- 理论收敛点：`p³ = 0.5` → `p ≈ 79.37%`，与 `targetAccuracy = 0.8` 一致。

### 2.2 Block 模式

- 每 **10 题**为一个 block（`blockSize = 10`）。
- `accuracy ≥ targetAccuracy` → 升一级；`accuracy < 0.5` → 降一级；中间维持。
- 用于"轮次评估"，给用户一个可感知的检查点。

两种模式共用同一 `targetAccuracy`。**不要**为某一张卡单独改收敛点——那会让跨卡的 Level 不可比。

## 3. 正确率不是进步指标

自适应算子把正确率**钉在阈值附近**：你变强，题变难，正确率回到 80%。因此：

- **正确率是收敛指示灯**，不是能力值。
- **Level 才是进步标尺**（当前阶、历史峰值、平均阶）。
- 结算页可以把正确率降级为辅助信息，但不得让它成为主视觉或主排序。

这条约束会影响所有视图：首页卡片、结算弹窗、统计大盘、计划摘要。任何"用正确率证明进步"的设计都与自适应机制自相矛盾。

## 4. 难度必须定义在感知空间

### 4.1 色感：ΔE_OK 而非 HSV 度数

HSV 不是感知均匀空间：低饱和区偏 35° 与高饱和区偏 4° 的视觉差异可能等价。用原始度数做容差会同时产生"不可答的色相题"和"过严的高饱和题"。

现行实现（`src/core/color/oklchUtils.ts#getTargetDeltaEForLevel`）：

```
Level 1  → ΔE = 0.12（约 40 JND）
Level 35 → ΔE = 0.008（约 2.5 JND）
中间按指数插值：ΔE = 0.12 × (0.008 / 0.12) ^ ((level - 1) / 34)
```

指数映射保证相邻 Level 的可辨难度等比递进，而不是线性稀释。

### 4.2 寻星：视角缩放而非固定像素

固定 20px 步长会让远端题偏易、近端偏难（韦伯–费希纳）。现行方案按锚点到真值点的距离反比缩放步长（`S: 25 → 3.5`，1/|AB|），单锚点用极坐标扇形网格，双锚点用双极射线交点。**难度是感知量，不是像素量。**

### 4.3 坏题的判据

一道题如果不能被感知区分，它就不是难题，而是噪声。生成器必须在出题时过滤：

- 低饱和 / 低明度区的色相题（不可辨）；
- 贴近 sRGB 色域边界的题（选项被裁剪后坍塌）；
- 干扰项可以被"看颜色深浅""求平均色"等策略作弊的题。

## 5. 同时对比类卡片的真值

明度补偿、色相诱导等卡片没有可用的实测心理物理数据，因此判定的是**合成诱导模型**：

```
shift = −k × (背景 − 中心)
k = 0.25（明度） / 0.22（色相）
```

含义是"命中 = 与模型预测一致"，**不等于**"与人眼感知相等"。这是已知局限：k 实际上决定了卡片严格度，模型误差会直接变成用户的"错误"。若未来引入实测 JND 数据，先复核 k 值，再评估是否需要改判分。

## 6. 指标与视图

| 指标 | 语义 | 用途 |
|---|---|---|
| Level | 当前可稳定完成的难度档 | 主指标 |
| 正确率 | 是否收敛在 80% 附近 | 收敛指示灯 |
| 响应时间 | 熟练度与犹豫 | 辅助诊断 |
| SAT / 难度瓶颈 | 通用分析层（`universalViews.tsx`） | 跨卡诊断 |

通用分析层目前只有 SAT 与难度瓶颈两项；疲劳、失误后崩盘、生物钟三项**未实现**（需要先有分箱阈值的校准依据，否则是伪精确）。

## 7. 已知局限

- **Level 的标定基准是作者经验**，不是外部人群数据。跨用户比较 Level 只能同卡同版本。
- **诱导模型是近似**，k 值未被实验校准。
- **负形比例的合法区间**（约 15%–80%）来自生成器拒绝采样，不是感知实验结论。
- 正确率在 block 模式与阶梯模式下语义略有差异，跨模式比较需注明。
